# BYD Sales Model Guide

전시장 고객 설명용 BYD 차종별 모바일 카탈로그입니다.

## 바로 사용
- PC: `index.html` 더블클릭
- 모바일/태블릿: GitHub Pages에 올린 뒤 생성된 주소 접속
- 검색창: `통풍`, `HUD`, `V2L`, `열선`, `Dynaudio` 등으로 사양 검색
- `PDF로 인쇄/저장`: 현재 차종 페이지를 PDF로 저장

## GitHub Pages 배포
1. GitHub에서 새 저장소 생성 (예: `byd-sales-guide`)
2. `index.html`을 저장소 최상위(root)에 업로드
3. `Settings → Pages`
4. `Build and deployment → Deploy from a branch`
5. Branch `main`, Folder `/(root)` 선택 후 Save
6. 생성된 Pages 주소를 휴대폰/태블릿 홈 화면에 추가

## 자료 기준
- BYD Korea 공식 홈페이지
- BYD Korea 공식 차종 카탈로그
- 기준일: 2026-08-16

※ 실제 계약/출고 사양은 계약 시점 공식 자료를 최종 확인하세요.


## 등급 구분 방식
- 기본/공통 사양과 **상위등급에서 추가되는 사양**을 별도 카드로 표시합니다.
- DOLPHIN: Active 추가 사양
- SEAL: Plus 추가 사양 → Dynamic AWD 추가 업그레이드
- SEALION 7: Plus 추가 사양
- 단일 등급 차종은 별도 추가사양 카드가 표시되지 않습니다.
- 기존 `고객 설명 포인트` 명칭은 `핵심 요약`으로 변경했습니다.


## V3 추가 기능
- 상위 트림 추가 사양을 **노란색 계열**로 표시
- 퍼포먼스/AWD 추가 사양을 **붉은색 계열**로 표시
- 각 모델 상단에 `BYD 사양 / 경쟁차종 비교` 전환 탭 추가
- 경쟁차 비교 항목: 가격, 차체크기, 축거, 배터리/시스템, 출력, 토크, 구동, 주행거리, 전비/연비, 0-100km/h, 핵심 특징
- 경쟁차 비교 수치는 2026-08-16 확인 가능한 제조사 공식 자료를 우선 사용하며, 제조사 비공개/표시기준 차이가 있는 항목은 별도 표기
